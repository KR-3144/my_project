# Консольный калькулятор с историей операций

Итоговый проект по программе «Python-разработчик с использованием инструментов ИИ».
Кейс 1: разработка консольного калькулятора с сохранением истории операций.

## Описание

Консольное приложение на Python выполняет базовые математические операции
(сложение, вычитание, умножение, деление) с целыми и десятичными числами.
Каждая операция автоматически сохраняется в текстовый файл `history.txt`
с датой и временем. Историю можно просмотреть на экране и очистить.

## Возможности

- Четыре арифметические операции: `+`, `-`, `*`, `/`
- Работа с целыми и десятичными числами (поддерживается ввод через точку и запятую)
- Автоматическое сохранение истории операций в текстовый файл `history.txt`
- Просмотр истории с датой и временем каждой операции
- Очистка истории с подтверждением
- Обработка ошибок: деление на ноль, некорректный ввод, пустой ввод

## Требования к окружению

- Python 3.8 или новее (при установке на Windows отметьте галочку
  «Add Python to PATH»)
- Внешние библиотеки не требуются: используются встроенные модули `os` и `datetime`

## Установка и запуск

1. Скачайте файлы `calculator.py` и `start_calculator.bat` в одну папку.
2. Запустите двойным щелчком файл `start_calculator.bat`
   (или выполните команду `python calculator.py` в терминале).
3. Файл истории `history.txt` создаётся автоматически при первой операции
   в папке проекта.

## Структура проекта

```
project/
├── calculator.py          # исходный код приложения
├── start_calculator.bat   # файл запуска для Windows
└── history.txt            # история операций (создаётся автоматически)
```

## Меню программы

```
1 - Сложение
2 - Вычитание
3 - Умножение
4 - Деление
5 - Показать историю операций
6 - Очистить историю
0 - Выход
```

## Использование ИИ-инструментов

С помощью ИИ-инструмента GitHub Copilot сгенерированы и доработаны вручную:

- `get_number` — валидация ввода пользователя (проверка числа, замена запятой
  на точку, обработка пустого ввода);
- `save_to_history` и `read_history` — сохранение и чтение истории операций
  в текстовом файле.
