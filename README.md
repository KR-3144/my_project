# Консольный калькулятор (Python)

Учебный проект итоговой работы по программе
«Python-разработчик с использованием инструментов ИИ» (группа «ПР-5-Р», кейс № 1).

Консольное приложение на чистом Python: базовые арифметические операции,
работа с целыми и десятичными числами, сохранение истории вычислений
в текстовый файл, защита от некорректного ввода.

## Возможности

- четыре арифметические операции: сложение, вычитание, умножение, деление;
- целые и десятичные числа (запятая в вводе заменяется на точку автоматически);
- история вычислений с датой и временем каждой операции (файл `history.txt`);
- защита от ошибок: деление на ноль, пустой и нечисловой ввод,
  несуществующий пункт меню, ошибки файловых операций — программа не падает;
- простое расширение: операции оформлены словарём, новая операция — одна строка.

## Требования

- ОС Windows 7 и выше (запуск через `start_calculator.bat`);
  на Linux/macOS возможен прямой запуск `python3 calculator.py`;
- Python 3.8+ (при установке отметить «Add Python to PATH»);
- сторонние библиотеки не требуются — только стандартная библиотека
  (`datetime`, `pathlib`, `math`).

## Запуск

1. Поместите файлы `calculator.py` и `start_calculator.bat` в одну папку,
   например `C:\Калькулятор`.
2. Запустите `start_calculator.bat` двойным щелчком — откроется окно с меню.

Батник сначала переходит в свою директорию (`cd /d "%~dp0"`), поэтому
`history.txt` гарантированно создаётся в папке проекта.

## Структура кода (calculator.py)

- `get_number(prompt)` — валидация ввода числа: цикл запроса, проверка
  пустой строки, замена запятой на точку, контроль нечисловых
  и «бесконечных» значений (`math.isfinite`).
- `format_number(number)` — отображение целых чисел без лишней десятичной части.
- `save_to_history(operation, result)` — дописывает операцию с датой
  и временем в `history.txt` (кодировка UTF-8, обработка `OSError`).
- `read_history()` — читает историю: возвращает список записей
  или пустой список, если файла ещё нет (`FileNotFoundError`).
- `main()` — меню, словарь операций и главный цикл приложения.

## Примеры работы

```
Выберите пункт: 1
Введите первое число: 12
Введите второе число: 8
Результат: 12 + 8 = 20

Выберите пункт: 4
Введите первое число: 5
Введите второе число: 0
На ноль делить нельзя!
```

Содержимое `history.txt`:

```
07.11.2026 13:45:02 | 12 + 8 = 20
07.11.2026 13:45:31 | 2.5 * 4.2 = 10.5
```

## Тестирование

| Сценарий | Ожидаемый результат | Статус |
|---|---|---|
| Сложение 12 + 8 | Результат 20, запись в историю | Пройден |
| Умножение 2,5 * 4,2 (запятая) | Результат 10.5 | Пройден |
| Деление 5 / 0 | «На ноль делить нельзя», программа работает | Пройден |
| Ввод «abc» вместо числа | Повторный запрос ввода | Пройден |
| Пустой ввод числа | «Ввод не должен быть пустым» | Пройден |
| Несуществующий пункт меню | «Такого пункта меню нет» | Пройден |
| История при отсутствии файла | «История пока пуста» | Пройден |
| Выход (пункт 0) | «Работа калькулятора завершена» | Пройден |

## Применение ИИ-инструмента

Функции `get_number`, `save_to_history`, `read_history` сгенерированы
с помощью GitHub Copilot и доработаны вручную: добавлен параметр `prompt`,
проверка `math.isfinite`, аккуратное форматирование выражения и обработка `OSError`.
